# E-Commerce Sales Analysis using Python

## Project Overview

This project analyzes a real-world E-commerce dataset from Olist to identify sales trends, customer behavior, product performance, and business opportunities. The analysis was performed using Python, Pandas, NumPy, Matplotlib, and Seaborn.

---

## Objectives

* Perform data cleaning and preprocessing.
* Analyze sales performance across product categories.
* Identify top-performing states and regions.
* Study customer review patterns.
* Calculate key business KPIs.
* Generate actionable business insights.

---

## Dataset Used

The project uses the Olist E-Commerce Dataset containing:

* Customers Dataset
* Orders Dataset
* Order Items Dataset
* Order Payments Dataset
* Order Reviews Dataset
* Products Dataset
* Sellers Dataset
* Geolocation Dataset

## Key Insights

* Health & Beauty is the highest revenue-generating category.
* A small number of states contribute the majority of sales.
* Customer satisfaction is generally high with most ratings being 4 and 5.
* Revenue is concentrated among a few high-performing categories.
* Customer spending remains relatively stable across orders.
